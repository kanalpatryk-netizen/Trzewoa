# Trzewia — v4.1 beta (komputer)

Nowa wersja na komputer, zbudowana na 4.0 beta. Wersje v3 i 4.0 beta zostają bez zmian.

**[⬇️ Pobierz trzewia-v4.1-beta.html](https://github.com/kanalpatryk-netizen/Trzewoa/releases/latest/download/trzewia-v4.1-beta.html)**
i otwórz w przeglądarce.

Nowości:
- **Cechy nacji** — każda nacja rodzi się *pobożna*, *płodna*, *wojownicza*, *kopiąca*, *długowieczna* albo *skromna*:
  jedna zaleta i jedna wada. Widać to na podpisie przy gnieździe, na karcie mieszkańca i w atlasie.
- **Łańcuchy kart** — wybory wracają po czasie: uciszony prorok jako heretyk, wysłuchany jako proroctwo,
  nakarmiona nacja jako wdzięczni, przetrwana zaraza jako ozdrowieńcy, przegrana wojna jako prośba o pomstę.
- **Świat dnia** — w menu: jedna góra na cały dzień, ta sama dla każdego; najlepszy czas zostaje w przeglądarce.
- **Osiągnięcia** — 11 celów dodatkowych (np. wygraj w 8 minut, na Koszmarze, bez wojen); lista w menu.
- Wszystko z 4.0 beta: dziennik dewelopera, Koszmar, statystyki, płynność przy tłumie.

```bash
npm install && npm run dev   # gra w przeglądarce
npm run pack                 # trzewia.html — jeden plik
npm test
```
