# Trzewia

Jesteś górą. W twoich korytarzach żyją ludy — karmisz je, szepczesz im do głów
i decydujesz, co ich spotka. Wygrywasz, gdy wierni dokopią się do twojego rdzenia i cię uwolnią.

## Jak grać

- **Nakarm** — przeciągnij palcem tam, gdzie mieszkają. Wyrośnie grzyb.
- **Szepnij „módl się”** — wierny idzie pod rdzeń. Trzech wiernych kruszy skorupę.
- **Cud** — przy gnieździe. Ta nacja mocniej w ciebie wierzy.
- **Karty wydarzeń** — co chwilę czas staje: najazd, zaraza, głód, wojna… Wybierasz, co z tym zrobić.

Przegrywasz, gdy góra zaśnie: gdy jedna rasa zje resztę albo wszyscy wymrą.
Samouczek pokazuje wszystko palcem.
