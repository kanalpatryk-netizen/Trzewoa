# Trzewia — v4 beta (komputer)

Nowa wersja na komputer, zbudowana na v3. v3 zostaje bez zmian.

**[⬇️ Pobierz trzewia-v4-beta.html](https://github.com/kanalpatryk-netizen/Trzewoa/releases/latest/download/trzewia-v4-beta.html)**
i otwórz w przeglądarce.

Nowości:
- **Dziennik dewelopera** — Ustawienia → Deweloper → *Tryb deweloperski*. W grze otwiera się okienko
  z logami świata (kto się modli, który blok zniknął, zgony, narodziny, karty) i narzędziami
  (+wiara, +krew, pęknięcie skorupy, tempo ×10/×20, wymuszenie karty). Klik we wpis = kamera tam.
- **Karty z odroczonym skutkiem** — „Układ z głębią” i „Przysięga dwóch nacji”.
- **Trudność „Koszmar”** — Ustawienia → Świat → Góra.
- **Statystyki** na ekranie końcowym.

```bash
npm install && npm run dev   # gra w przeglądarce
npm run pack                 # trzewia.html — jeden plik
npm test
```
